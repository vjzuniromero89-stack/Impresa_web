# IMPRESA — Web demo

Sitio estático responsive listo para abrir o desplegar.

## Incluye
- Inicio, Servicios, Diseña tu camisa, Tienda, Galería, Nosotros y Contacto.
- Selector Hombre/Mujer/Niño/Niña.
- Distribución de cantidades por talla.
- Vista 2D y demostración 360°.
- Carga de diseño y reglas demo de compatibilidad de técnicas.
- Tienda separada para productos de precio fijo.
- Modal para videos del proceso.

## Importante antes de producción
Las tarifas son demostrativas. El análisis automático del arte y los modelos 3D reales requieren conectar un backend/servicio de análisis y cargar modelos 3D de las prendas reales. También deben reemplazarse contacto, productos, imágenes y videos por los datos oficiales.

## Ejecutar
Abre `index.html` directamente o sirve la carpeta con cualquier servidor estático. Para Vercel, sube la carpeta/repo y despliega como sitio estático.
